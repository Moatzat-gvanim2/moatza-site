# מועצת התלמידים — גוונים

אתר סטטי המתאים ל-GitHub Pages. אין צורך ב-Node או בשרת צד-שרת.

## פרסום ב-GitHub Pages

1. העלו את תוכן התיקייה הזאת למאגר GitHub.
2. פתחו **Settings → Pages** במאגר.
3. בחרו **Deploy from a branch**, את הענף `main` ואת התיקייה `/(root)`, ושמרו.
4. פתחו את כתובת האתר ש-GitHub Pages מציג.

האתר טוען את הפעילויות מ-`PROJECTS/projects.json`. פעולות מנהל נשמרות מקומית בדפדפן. כדי לפרסם אותן לקהל, הורידו JSON מאזור הניהול, החליפו את קובץ הנתונים במאגר, והעלו את השינוי ל-GitHub. הפרטים המלאים נמצאים ב-`PROJECTS/README.md`.

סיסמת הכניסה היא `gvanim2026!`. באתר סטטי היא מופיעה בקוד ולא מגינה על נתונים או על פעולות מפני משתמשים טכניים. אין להזין מידע פרטי בטופס הרעיונות; הוא נשמר בדפדפן בלבד.
